# About this copy

> **Intentionally vulnerable. Never deploy, install or run this outside an isolated lab.**

This is a private copy of [OWASP Juice Shop](https://github.com/juice-shop/juice-shop)
**v20.3.0** (released 2026-10-11), imported as a single snapshot of that release — its
history is upstream. It is used to test the platform's connectors against real scanner
results and to demonstrate the platform to customers.

- **License:** MIT, unchanged — see `LICENSE`. Copyright Bjoern Kimminich and the OWASP
  Juice Shop contributors.
- **Fake secrets on purpose.** `ctf.key`, `encryptionkeys/` and others are part of Juice
  Shop's training challenges. They are not credentials for anything.
- **Not modified**, apart from this file. Upgrading means importing a newer release, at
  least seven days old, as a new commit.
- **Dependabot security updates stay off:** a fix would remove what this copy is for.
  Alerts stay on.

`aaronweaver/juice-shop` is an unrelated public fork from 2016 and is left as it is.
